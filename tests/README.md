# اختبارات حساباتي

حزمة اختبارات آلية (Playwright) تغطي أهم الإصلاحات والميزات التي يسهل أن تنكسر دون أن يُلاحَظ:
فقدان الأحرف بالبحث، التحقق من المبالغ السالبة ورقم الجوال، حذف/عرض ملاحظات حركات حساب الزبون،
Pagination، تصدير CSV، البحث العام، مؤشر حالة المزامنة، ضغط صور المرفقات، وشاشة الترحيب.

## التشغيل

```bash
npm install
npx playwright install chromium   # مرة واحدة فقط
npm test
```

كل ملف `*.test.js` مستقل ويمكن تشغيله منفردًا: `node tests/customers-ledger.test.js` مثلًا.

## كيف تعمل

- `_harness.js`: يشغّل خادم ملفات ثابت محلي للمستودع (بدون أي خادم build) + متصفح Chromium حقيقي،
  ويوفّر `assert(name, condition)` بسيطة تطبع ✅/❌ لكل حالة بدل إيقاف الاختبار عند أول فشل.
- كل اختبار يحمّل `index.html` فعليًا، يبذر بياناته عبر استدعاء مباشر لدوال `js/database.js`
  (بدون تمرير بواجهة الإعداد/الدخول)، ثم يستورد شاشة الواجهة المطلوبة ويتفاعل معها بضغطات/كتابة حقيقية.
- لا تحتاج هذه الاختبارات اتصالًا بسوبابيس: `backendMode` الافتراضي محليًا كافٍ لتشغيل منطق الأعمال
  (IndexedDB) بدون شبكة؛ أي اختبار يحتاج تسجيل دخول فعلي يُحقنه مباشرة عبر `updateSettings(...)`.

## ملاحظة بيئة التطوير التي كُتبت فيها هذه الحزمة

إن لم يتعرّف Playwright على مسار Chromium تلقائيًا ببيئتك (نادر بعد `npx playwright install`)، مرّر
`PLAYWRIGHT_CHROMIUM_PATH=/path/to/chrome npm test`.
